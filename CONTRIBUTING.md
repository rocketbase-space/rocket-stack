# Contributing to Rocket Stack

Thanks for your interest in improving Rocket Stack.

## How to contribute

1. Fork the repository and create a branch from `main`.
2. Keep changes focused: one skill or one fix per pull request.
3. Each skill lives in its own folder with a `SKILL.md`. Follow the structure of the existing skills.
4. Open a pull request with a short description of what changed and why.

## Reporting issues

Use GitHub Issues for bugs and ideas. For security problems, see [SECURITY.md](SECURITY.md).
